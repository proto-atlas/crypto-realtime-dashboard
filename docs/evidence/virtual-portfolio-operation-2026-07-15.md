## 対象commit時点の仕様

- 追加・減らすは、仮想保有に対する操作種別として選択する
- 選択中の操作は色と`aria-pressed`で示す
- 実行ボタンには、銘柄、数量、操作を表示する
- 初期状態では`BTCを0.1追加する`と表示する
- 実行ボタンのクリックと、数量入力でのEnterの両方でフォームを送信する
- 実行結果はメッセージ、仮想現金、仮想保有、直近の仮想更新へ反映する

## 変更理由

以前の追加・減らすボタンは操作種別の選択に使われていましたが、ボタン名だけでは選択と実行の違いが分かりにくい状態でした。また、実行ボタンの`仮想ポジションを更新`という表示からは、対象銘柄、数量、操作を判断できませんでした。

操作種別の選択状態を維持しつつ、実行ボタンに具体的な処理内容を表示する構成へ変更しました。

## 確認方法と結果

### 単体・統合テスト

- 方法: `pnpm check`
- 対象: Biome、typecheck、Node.jsスクリプトテスト、shared-types、BFF、Web、production build
- 結果: Node.jsスクリプト4件、shared-types 7件、BFF 72件、Web 109件の計192件が通過し、Biome、typecheck、buildも通過
- UI固有の結果: 初期数量`0.1`での追加実行と、減らす選択後の保有不足表示を確認

### Playwright E2E

- 方法: `pnpm e2e`
- 対象: Chromiumでのデモ操作、ローソク足canvas、仮想ポートフォリオ、WebSocket予備接続、レスポンシブ表示
- 結果: 11件すべて通過
- UI固有の結果: 初期数量`0.1`のまま実行ボタンをクリックして追加できること、数量入力でEnterを押して追加できることを確認

## 確認していないこと

- スクリーンリーダー実機での読み上げ順序
- モバイル実機での長時間操作
- localStorageを制限したブラウザでの永続性
- 実取引、送金、取引所アカウント連携
